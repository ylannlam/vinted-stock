# Stock Vinted — relevé Shein (première version)

1. Décompressez le ZIP dans un dossier que vous conservez.
2. Dans Chrome, ouvrez `chrome://extensions` (Edge : `edge://extensions`).
3. Activez **Mode développeur**, cliquez sur **Charger l’extension non empaquetée**, sélectionnez le dossier contenant `manifest.json`.
4. Ouvrez une fiche sur **fr.shein.com**, puis cliquez sur l’extension et **Lire la fiche ouverte**.
5. Cliquez sur **Vérifier dans mon catalogue**, connectez-vous à Stock Vinted si nécessaire, vérifiez les données et enregistrez.

L’extension intervient uniquement à votre clic. Elle ne lit pas les cookies, ne conserve aucune clé et n’effectue aucun achat. Elle utilise les informations structurées présentes dans la page. Lorsqu’un prix est ambigu ou absent, le champ reste vide. Taille, couleur et disponibilité sont confirmées manuellement. Les coupons du panier ne sont pas calculés. Si Shein affiche une vérification, terminez-la vous-même normalement.

Cette version ne surveille pas les prix en arrière-plan. Les modifications du site Shein peuvent nécessiter une mise à jour de l’extension. Une relecture dans le catalogue est obligatoire avant toute écriture.
