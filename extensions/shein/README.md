# Stock Vinted — relevé Shein 0.2.0

1. Décompressez le ZIP dans un dossier que vous conservez.
2. Dans Chrome, ouvrez `chrome://extensions` (Edge : `edge://extensions`).
3. Activez **Mode développeur**, cliquez sur **Charger l’extension non empaquetée**, sélectionnez le dossier contenant `manifest.json`.
4. Ouvrez une fiche sur **fr.shein.com**, puis cliquez sur l’extension et **Lire la fiche ouverte**.
5. Cliquez sur **Vérifier dans mon catalogue**, connectez-vous à Stock Vinted si nécessaire, vérifiez les données et enregistrez.

Cette extension s'utilise dans votre navigateur habituel, sans run.bat et sans code d'association. Elle sert aussi de recours si Shein refuse la fenêtre du programme PC.

L’extension intervient uniquement à votre clic. Elle ne lit pas les cookies, ne conserve aucune clé et n’effectue aucun achat. Elle privilégie le SKU et le prix affichés sur la fiche, puis les informations structurées si le prix affiché est absent. Un prix ambigu reste vide. La taille et la couleur sélectionnées sont préremplies quand elles sont lisibles. Vérifiez-les, confirmez la disponibilité et choisissez le SKU Dotb à associer dans le catalogue. Les coupons du panier ne sont pas calculés. Si Shein affiche une vérification, terminez-la vous-même normalement.

Cette version ne surveille pas les prix en arrière-plan. Les modifications du site Shein peuvent nécessiter une mise à jour de l’extension. Une relecture dans le catalogue est obligatoire avant toute écriture.
